  ## WHAT THIS APP DOES

  Bargaining Power AI is a multi-tenant SaaS app. Users upload a teacher union CBA (collective bargaining          
  agreement) PDF and optionally an employee roster CSV/XLSX. The app uses Claude AI to extract the CBA data and
  then generate a comprehensive multi-year employer/employee cost model as a downloadable Excel workbook (.xlsx)   
  built with Python openpyxl.                                                                                    

  Flow:                                                                                                            
  1. User registers → creates an org account
  2. User creates a project (CBA name, state, contract years)                                                      
  3. User uploads CBA PDF → clicks "Extract Data" → Claude Sonnet reads the PDF and extracts salary schedule,      
  retirement rates, benefits, annual increases into structured JSON                                                
  4. User clicks "Generate Model" → Claude Opus receives all 7 skill domain files as system prompt + extracted CBA 
  data → writes Python/openpyxl code → the server executes it with python3 → saves the .xlsx to disk → user        
  downloads it

  KNOWN ISSUES TO WATCH FOR                                                                                        
                                                                                                                 
  Issue 1: NEXTAUTH_URL mismatch
  If login redirects to the wrong URL or you get a CSRF error, the NEXTAUTH_URL secret doesn't match the actual    
  Replit webview URL. Update the secret to the exact URL shown in the browser address bar.                         
                                                                                                                   
  Issue 2: Python execution timeout                                                                                
  The generate step calls Claude Opus which takes 60–120 seconds to write the Python, then executes it. The default
   Next.js route timeout may be too short. If generation times out, add this to next.config.ts:                    
  export const maxDuration = 180; // seconds                                                                     
                                                                                                                   
  Issue 3: File not found after upload                                                                           
  If the extract step fails with "file not found", the .uploads directory wasn't created or the app's working      
  directory is different than expected. The upload path is controlled by the UPLOAD_DIR env var (defaults to       
  .uploads/ relative to process.cwd()). Set UPLOAD_DIR to an absolute path if needed, e.g.:                        
  UPLOAD_DIR=/home/runner/Labor-Forecaster/artifacts/bargaining-power-ai/.uploads                                  
                                                                                                                   
  Issue 4: Claude API document type error
  The extract route sends PDF files as base64 document blocks to Claude. If you get a model error saying "document 
  type not supported", the PDF is a scanned image-only document. Claude requires text-layer PDFs. The app will     
  still try, but extraction quality will be lower.                                                                 
                                                                                                                   
  Issue 5: openpyxl not found during generation                                                                  
  If you see ModuleNotFoundError: No module named 'openpyxl' in the cost model error, run pip3 install openpyxl
  again and confirm which python3 matches the python3 that pnpm exec would call.

  HOW THE DUAL-MODEL AI PIPELINE WORKS                                                                           
                                                                                                                   
  Extraction (Step 1 — Claude Sonnet):
  - Route: POST /api/projects/[id]/extract                                                                         
  - Model: claude-sonnet-4-6                                                                                     
  - Input: base64-encoded PDF file sent as a document block                                                        
  - System prompt: DOMAIN-CBA-INTERPRETATION.md (teaches Claude how to read a CBA)                                 
  - Output: JSON with salary schedule, retirement rates, insurance, annual increases
  - Stored in: bp_uploads.extracted_data (JSONB)                                                                   
                                                                                                                   
  Cost Model Generation (Step 2 — Claude Opus):                                                                    
  - Route: POST /api/projects/[id]/generate                                                                        
  - Model: claude-opus-4-6                                                                                       
  - System prompt: All 7 skill .md files concatenated (SKILL.md + 4 DOMAIN files + 2 OUTPUT files)                 
  - Input: The extracted CBA JSON + employee roster (or instruction to synthesize one)                           
  - Output: Complete Python script using openpyxl that builds a 7-tab Excel workbook                               
  - Execution: The server runs the Python script with child_process.exec('python3 script.py')                      
  - Result: .xlsx file saved to .uploads/, path stored in bp_cost_models.output_file_path                          
                                                                                                                   
  Download:                                                                                                        
  - Route: GET /api/projects/[id]/download?modelId=[uuid]                                                          
  - Reads the .xlsx file from disk, streams it as application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
